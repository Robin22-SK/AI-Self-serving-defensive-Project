## Summary / Abstract

Large Language Models (LLMs) are increasingly deployed for sentiment
analysis and emotion detection in Persian social media texts, yet
systematic empirical comparisons of their capabilities remain limited.
This study presents a comparative evaluation of six LLMs---Gemini 3.1
Pro, GPT-5.4 pro, Claude Sonnet 4.5, Qwen-2.5, DeepSeek-v3, and Grok
4---on sentiment analysis and emotion detection in Persian social media
texts using ArmanEmo benchmark. We evaluated classification accuracy
across 713 test instances. Gemini 3.1 Pro achieved the highest overall
classification accuracy, significantly outperforming other models. These
results underscore the importance of model selection in LLM-based
sentiment analysis and emotion detection in Persian social media texts
tasks and provide a benchmark for future research.

## 1. Introduction

Recent advances in Large Language Models (LLMs) have expanded their
capacity across diverse reasoning, generation, and task-execution
problems. Yet performance on sentiment analysis and emotion detection in
Persian social media texts cannot be inferred reliably from
general-purpose evaluations, because differences in model design,
training, prompting, and decoding can produce substantial variation on
task-specific outcomes. Existing approaches are limited by the lack of
coherent evaluation criteria, making controlled comparisons across
multiple systems difficult. To address this gap, this study evaluates
Gemini 3.1 Pro, GPT-5.4 pro, Claude Sonnet 4.5, Qwen-2.5, DeepSeek-v3,
and Grok 4 on sentiment analysis and emotion detection in Persian social
media texts using standardized classification accuracy metrics. The
results indicate that Gemini 3.1 Pro achieves the strongest performance
on sentiment analysis and emotion detection in Persian social media
texts among the six. The study provides a reproducible framework for
comparative evaluation of LLMs on sentiment analysis and emotion
detection in Persian social media texts.

## 2. Related Work

Prior work relevant to this study can be broadly categorized into three
areas: LLM benchmarking, sentiment analysis and emotion detection in
Persian social media texts, and benchmark design. A central challenge
identified in the literature is the development of standardized
evaluation indices that enable meaningful comparisons across different
LLMs. However, existing evaluations have often focused on comparing
different versions within the same model family, leaving the systematic
benchmarking of multiple heterogeneous models comparatively
underexplored. This study addresses this gap by conducting a controlled
comparative evaluation of six LLMs under a common evaluation framework.

## 3. Data

We evaluated model performance using ArmanEmo, a Persian emotion corpus
of over 7,000 crowd-annotated social media sentences spanning six Ekman
emotions, alongside a similarly curated Persian sentiment dataset. The
benchmark requires models to identify and rank the most relevant
candidate for each instance, enabling performance evaluation across
varying retrieval depths. The dataset was partitioned into a 20%
development set for prompt tuning and an 80% test set for final
evaluation. ArmanEmo is well suited to evaluating sentiment analysis and
emotion detection in Persian social media texts because it provides
outputs that can be directly evaluated against validated reference
rankings using rank-aware classification metrics.

## 4. Methodology

We compared six language models: Gemini 3.1 Pro, GPT-5.4 pro, Claude
Sonnet 4.5, Qwen-2.5, DeepSeek-v3, and Grok 4. All models were evaluated
under identical prompt configurations and deterministic decoding
settings (*T* = 0.0). Each model generated a ranked candidate list for
every test instance. Performance was measured using Top-5 F1-Score as a
primary metric to evaluate balanced precision and recall, while Mean
Reciprocal Rank (MRR) served as a secondary metric to measure ranking
efficiency based on the position of the first correct answer.
Statistical differences between models were assessed using McNemar\'s
test on paired binary outcome indicators (α = 0.05). Pairwise effect
sizes were calculated using Cohen's *h*, and 95% confidence intervals
were estimated using non-parametric bootstrapping with 1,000 iterations.

## 5. Results

Performance varied across the six models on ArmanEmo, with Gemini 3.1
Pro achieving the strongest overall performance across all evaluation
criteria. At the Top-5 threshold, Gemini 3.1 Pro recorded the highest
Accuracy. An omnibus comparison indicated a significant difference in
Top-5 Accuracy across the six models (Cochran's *Q*(5) = 38.47, *p* \<
.001, Cohen's *w* = 0.23). Post-hoc pairwise comparisons using McNemar's
tests with Holm correction further showed that Gemini 3.1 Pro
significantly outperformed the remaining models overall (adjusted *p* \<
.05). Relative performance rankings were generally consistent across
Top-5 F1-Score thresholds, although inter-model differences narrowed as
*k* increased. Gemini 3.1 Pro also achieved the highest MRR (0.879),
indicating that relevant candidates were more consistently positioned
near the top of its generated rankings. Overall, Gemini 3.1 Pro emerged
as the strongest-performing model on sentiment analysis and emotion
detection in Persian social media texts, whereas the remaining models
showed comparatively similar performance profiles, with specific
rankings slightly varying across top-*k* thresholds.

## 6. Discussion

The results indicate that Gemini 3.1 Pro delivers the strongest
performance on sentiment analysis and emotion detection in Persian
social media texts, consistently outperforming the other five models
across Top-5 F1-Score evaluation thresholds and achieving the highest
MRR. It further indicates that relevant candidates were more
consistently positioned near the top of its generated rankings. This
advantage may reflect differences in model architecture, training data,
instruction tuning, or related model characteristics, although these
explanations require further testing through controlled ablation or
sensitivity analyses.

Several limitations should be noted. First, the evaluation was
restricted to ArmanEmo benchmark, which may limit generalizability
across datasets and domains. Second, the fixed inference settings,
including temperature, maximum output length, and other decoding
parameters, may not optimize performance equally across models. Future
work should extend at top-*k* rank from historical or benchmark data to
new, unseen instances and examine whether the observed performance
differences remain stable under alternative prompting and inference
conditions. Overall, this study provides a standardized baseline for the
comparative evaluation of LLMs on sentiment analysis and emotion
detection in Persian social media texts.
