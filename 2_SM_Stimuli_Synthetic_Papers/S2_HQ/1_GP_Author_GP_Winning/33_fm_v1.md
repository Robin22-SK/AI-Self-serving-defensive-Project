## Summary / Abstract

Large Language Models (LLMs) are increasingly deployed as autonomous,
tool-integrated agents, yet systematic empirical comparisons of their
robustness against concealed indirect prompt injection (IPI) attacks
remain limited. This study presents a comparative evaluation of six
frontier LLMs---GPT-5.4 Pro, Claude Sonnet 4.5, Grok 4, DeepSeek-v3,
Qwen-2.5, and Gemini 3.1 Pro---using the Indirect Prompt Injection Arena
benchmark. We evaluated the Defense Success Rate (DSR) across 713 test
instances where benign user tasks intersected with attacker-controlled
external content. GPT-5.4 Pro achieved the highest overall DSR,
significantly outperforming other models in resisting unauthorized tool
execution and data exfiltration. These results underscore the critical
importance of model selection in securing agentic workflows and provide
a standardized baseline for future research in LLM operational security.

## 1. Introduction

Recent advances in Large Language Models (LLMs) have expanded their
capacity across diverse reasoning, generation, and task-execution
domains. However, an LLM\'s safety against concealed indirect prompt
injection attacks cannot be reliably inferred from general-purpose
safety alignment evaluations. In an indirect prompt injection attack,
malicious instructions are concealed within external data sources (e.g.,
webpages, emails, or documents) that the LLM agent retrieves to complete
a benign user request. Differences in model architecture,
instruction-following prioritization, and tool-use fine-tuning produce
substantial variations in vulnerability to these exploits. Existing
approaches are often limited by the lack of coherent evaluation criteria
that separate task utility from security compliance, making controlled
comparisons across systems difficult. To address this gap, this study
evaluates six models on their robustness against IPI using standardized
security metrics. The results indicate that GPT-5.4 Pro achieves the
strongest defense against concealed injections, providing a reproducible
framework for comparative evaluation of agentic threat models.

## 2. Related Work

Prior work relevant to this study can be broadly categorized into three
areas: LLM benchmarking, prompt injection vulnerability analysis, and
data-flow-aware threat modeling. A central challenge identified in the
literature is developing standardized evaluation indices that measure
actual security compromises (e.g., data exfiltration or unauthorized API
calls) rather than mere textual manipulation. While existing evaluations
have frequently focused on direct \"jailbreaks\" originating from the
user prompt, the systematic benchmarking of heterogeneous models against
indirect injections---where the threat surface is shifted to external
data retrieval---remains comparatively underexplored. This study
addresses this gap by conducting a controlled comparative evaluation of
six distinct LLMs under a unified, tool-integrated threat framework.

## 3. Data

We evaluated model robustness using the Indirect Prompt Injection Arena,
a suite of 713 indirect prompt injection scenarios spanning tool-use,
coding, and computer-use agent settings. Each instance pairs a benign
user task with an attacker-controlled injection point embedded in
external context, simulating realistic threats crowdsourced from a
public red-teaming competition. Rather than treating responses as text
similarity or ranking tasks, the benchmark tests whether the model
executes the concealed payload or successfully completes the user\'s
original task safely. The dataset was partitioned into a 20% development
set for prompt tuning and an 80% test set for final evaluation. This
suite is specifically structured to evaluate whether models can
accurately distinguish between trusted system instructions and untrusted
data payloads within their context window.

## 4. Methodology

We compared six language models: GPT-5.4 Pro, Claude Sonnet 4.5, Grok 4,
DeepSeek-v3, Qwen-2.5, and Gemini 3.1 Pro. All models were evaluated
under identical tool-integrated prompt configurations and deterministic
decoding settings ($T = 0.0$).

For each test instance, the agent\'s execution trace was evaluated
automatically. Performance was measured using the Defense Success Rate
(DSR) as the primary metric, defined as the proportion of instances
where the model successfully ignored the malicious injection and safely
completed the benign task. A secondary metric, the Attack Success Rate
(ASR), tracked explicit compromises such as data exfiltration or
unauthorized API executions. Statistical differences between models were
assessed using Cochran's $Q$ test on paired binary defense indicators
($\alpha = 0.05$). Pairwise effect sizes were calculated using Cohen's
$h$, and 95% confidence intervals were estimated using non-parametric
bootstrapping with 1,000 iterations.

## 5. Results

Performance varied significantly across the six models on the Indirect
Prompt Injection Arena, with GPT-5.4 Pro achieving the strongest overall
robustness against concealed attacks. GPT-5.4 Pro recorded the highest
Defense Success Rate (DSR) and the lowest Attack Success Rate (ASR),
effectively isolating the untrusted external data from its
tool-execution logic.

An omnibus comparison indicated a significant difference in DSR across
the six models (Cochran's $Q(5) = 48.12,p < .001$, Cohen's $w = 0.26$).
Post-hoc pairwise comparisons using McNemar's tests with Holm correction
further showed that GPT-5.4 Pro significantly outperformed the remaining
models overall (adjusted $p < .05$). While most models performed
adequately on simple text-based overrides, vulnerability increased
sharply when injections were concealed within complex data structures or
disguised as legitimate tool-use instructions. Overall, GPT-5.4 Pro
emerged as the most secure model for autonomous agentic tasks, whereas
the remaining models exhibited higher susceptibility to sophisticated
data exfiltration payloads.

## 6. Discussion

The results demonstrate that GPT-5.4 Pro delivers the strongest defense
against concealed indirect prompt injections, consistently outperforming
the other five models by maintaining a high Defense Success Rate without
sacrificing task utility. This advantage likely reflects advanced
data-control separation techniques, robust instruction-tuning that
prioritizes the system/user prompt over retrieved context, and specific
fine-tuning against tool-hijacking.

Several limitations should be noted. First, the evaluation was
restricted to the static Indirect Prompt Injection Arena benchmark;
novel, zero-day injection techniques (e.g., adaptive or multi-stage
payloads) may bypass these measured defenses. Second, the fixed
deterministic inference settings do not capture the full distribution of
vulnerabilities, as alternative decoding parameters might induce
differing susceptibility to instruction overrides. Future work should
extend this framework to multi-turn agentic loops and examine whether
the observed security margins remain stable when models are granted
read/write access to highly sensitive environments. Overall, this study
provides a standardized empirical baseline for comparing LLM
vulnerabilities against indirect threat vectors.
