## Summary / Abstract

Large Language Models (LLMs) are increasingly deployed for fine-grained
token-level awareness and structured evaluation in multilingual text,
yet systematic empirical comparisons of their capabilities remain
compromised by mismatched evaluation metrics and vulnerability to
pre-training dataset contamination. This study presents a controlled,
contamination-resistant comparative evaluation of six state-of-the-art
LLMs---GPT-5.4 Pro, Claude Sonnet 4.5, Grok 4, Gemini 3.1 Pro,
DeepSeek-v3, and Qwen-2.5---on multilingual token and structural
reasoning. To isolate genuine subword comprehension from memorized
public benchmarks, we evaluate models across two datasets: a
standardized subset of the public TASE-Core benchmark (356 instances)
and a novel, sequestered zero-day dataset, MultilingualToken-ZeroDay
(357 unseen multilingual tasks featuring complex token boundary
alignments, script mixing, and structural constraints). Furthermore, we
replace flawed candidate-ranking metrics (Top-5 F1, MRR) with
task-aligned structural criteria---**Token Span Alignment F1 (TSA-F1)**,
**Structural Validity Rate (SVR)**, and **Multilingual Lexical Precision
(MLP)**---and introduce **Token-Structure Verification Chain-of-Thought
(TSV-CoT)**, a structured decoding strategy forcing models to explicitly
map subword tokenization boundaries and simulate token counts across
languages before emitting structured outputs. While GPT-5.4 Pro achieved
the highest baseline SVR ($0.85$) on the public dataset, all models
exhibited a statistically significant 21--25% performance degradation on
the zero-day benchmark, exposing extensive pre-training data
contamination. Crucially, TSV-CoT systematically improved token
awareness and structural accuracy across all six models (+0.14 average
SVR lift). These findings establish a rigorous baseline for evaluating
fine-grained LLM capabilities across diverse linguistic scripts.

## 1. Introduction

Recent advances in Large Language Models (LLMs) have expanded their
capacity across diverse reasoning, code generation, and semantic
instruction-following tasks. Yet, performance on low-level, fine-grained
tasks---such as counting specific characters, reversing subword
sequences, identifying rare token boundaries, and parsing structured
multilingual formats (spanning English, Chinese, and Korean)---cannot be
inferred reliably from general-purpose high-level benchmarks. Subword
tokenizers (e.g., Byte-Pair Encoding) partition morphologically diverse
scripts unevenly, making token-level counting and structural
manipulation notoriously prone to systemic errors (exemplified by
classic failures in character-counting prompts like \"strawberry\").

Existing evaluations of LLM performance on token-level awareness
frequently suffer from two methodological flaws:

1.  **Mismatched Evaluation Criteria:** Previous studies have improperly
    modeled fine-grained token manipulation and structural evaluation as
    a candidate retrieval problem, applying generic ranking metrics like
    Top-5 F1-Score or Mean Reciprocal Rank (MRR). Such metrics fail to
    evaluate whether a model precisely generates exact character/token
    sequences or validates rigid JSON/structural constraints.

2.  **Pre-Training Data Contamination:** Standardized multilingual token
    benchmarks, such as the TASE benchmark suite, utilize reproducible
    synthetic data pipelines. Because these generation scripts and
    evaluation sets have been circulated in public open-source
    repositories, modern web-scale pre-training corpora ingest these
    text-label pairs, allowing models to retrieve memorized token
    solutions rather than execute genuine algorithmic subword reasoning.

To address this gap, this study conducts a controlled comparative
evaluation of six frontier models under a dual-benchmark framework,
paired with a specialized subword verification reasoning scaffold
designed to bridge tokenization disparities across languages.

## 2. Related Work

Prior work relevant to this study spans fine-grained LLM evaluation,
subword tokenization analysis, and dataset contamination mitigation. A
central challenge identified in recent literature---particularly
highlighted by studies examining character-level counting failures and
cross-lingual tokenization overhead (e.g., Korean and Chinese script
token expansion compared to English)---is that transformer models
operate on abstract vector spaces removed from raw character strings.

Despite the introduction of fine-grained benchmarks like TASE, many
general evaluations continue to apply simplified, single-step prompting
to complex token-awareness tasks. Furthermore, while the community has
analyzed zero-shot performance on isolated English word puzzles,
controlled inter-model benchmarking that accounts for multilingual
tokenization alignment and dataset memorization remains underexplored.
This study addresses this gap by establishing domain-aligned structural
validation metrics alongside an uncontaminated zero-day benchmark suite
and an explicit subword verification methodology.

## 3. Data

We evaluated model performance across 713 total multilingual instances
partitioned into two distinct evaluation sets:

- **Public Baseline (TASE-Core):** A curated 356-instance subset derived
  from the public TASE benchmark, covering token frequency counts,
  length operations, difference identification, and structural
  JSON/multilingual formatting tasks across English, Chinese, and
  Korean. This set serves to measure baseline capability and potential
  pre-training memorization.

- **Zero-Day Evaluation (MultilingualToken-ZeroDay):** A novel,
  sequestered dataset of 357 instances generated post-knowledge-cutoff
  using programmatically verified scripts. These instances feature
  complex multi-script interleaving, rare Unicode character
  manipulation, and strict structural formatting rules designed to
  prevent memorization shortcuts.

## 4. Methodology

We compared six state-of-the-art language models: GPT-5.4 Pro, Claude
Sonnet 4.5, Grok 4, Gemini 3.1 Pro, DeepSeek-v3, and Qwen-2.5. All
models were evaluated under identical zero-shot prompt configurations
and deterministic decoding settings ($T = 0.0$). Models were tested
under two operational paradigms: Direct Generation and **Token-Structure
Verification Chain-of-Thought (TSV-CoT)**.

TSV-CoT mandates a three-stage structured reasoning trace before
outputting the final result:

1.  **Subword Tokenization & Script Parsing:** Explicitly break down the
    input string into constituent subword tokens according to the
    model\'s target tokenizer vocabulary, noting script-specific
    boundaries (e.g., CJK character vs. English subword chunking).

2.  **Structural Decomposition & Operation Simulation:** Step through
    the required token manipulation (e.g., counting, filtering,
    reordering, or schema validation) incrementally while maintaining a
    running tally state.

3.  **Self-Correction & Constraint Verification:** Cross-check the
    generated token array against structural constraints (length, exact
    character position, valid JSON syntax) before emitting the final
    response.

Rather than candidate retrieval metrics, performance was evaluated using
task-aligned structural indicators:

- **Token Span Alignment F1 (TSA-F1):** The harmonic mean of precision
  and recall measuring exact boundary alignment between predicted token
  spans and ground-truth token arrays.

- **Structural Validity Rate (SVR):** The strict accuracy of
  successfully satisfying complex syntactic or schema constraints (e.g.,
  exact token counts, schema conformance).

- **Multilingual Lexical Precision (MLP):** Character-level precision
  evaluated across English, Chinese, and Korean text transformations.

Statistical differences were assessed using an omnibus Cochran's Q test
on binarized task success indicators, followed by post-hoc pairwise
McNemar's tests with Holm-Bonferroni correction ($\alpha = 0.05$).
Effect sizes were calculated via Cohen's $w$, with 95% confidence
intervals estimated via non-parametric bootstrapping with 1,000
iterations.

## 5. Results

Performance varied significantly across models, reasoning paradigms, and
dataset contamination levels. On the public TASE-Core baseline, GPT-5.4
Pro achieved the highest direct Structural Validity Rate ($SVR = 0.85$)
and TSA-F1 ($0.83$). However, on the uncontaminated
MultilingualToken-ZeroDay dataset, all models exhibited severe, uniform
performance degradation. GPT-5.4 Pro\'s direct SVR dropped to 0.67,
while competing models displayed relative performance drops ranging from
21% to 25%.

An omnibus Cochran\'s Q test on the zero-day benchmark confirmed
statistically significant performance differences across the six models
($Cochran'sQ(5) = 45.83,p < .001,Cohen'sw = 0.27$). Post-hoc pairwise
McNemar's tests with Holm correction indicated that GPT-5.4 Pro
maintained a statistically significant lead over the remaining models
under unseen conditions ($adjustedp < .05$). Following GPT-5.4 Pro,
Claude Sonnet 4.5 ($SVR = 0.64$) and Gemini 3.1 Pro ($SVR = 0.62$)
demonstrated the strongest zero-day token awareness, whereas models with
higher tokenization overhead in non-English scripts struggled
significantly with character-level indexing.

The deployment of the **TSV-CoT** reasoning scaffold yielded
statistically significant performance recoveries across all six models
on the zero-day evaluation suite. GPT-5.4 Pro\'s SVR improved from 0.67
to 0.81, and Claude Sonnet 4.5 climbed from 0.64 to 0.78. On average,
SVR across all models saw a +0.14 lift under TSV-CoT. Error analysis
revealed that under direct generation, models frequently suffered from
\"subword hallucination\" (assuming character counts based on semantic
embedding rather than explicit token boundaries); TSV-CoT\'s explicit
token-mapping phase effectively eliminated these arithmetic disconnects,
boosting average MLP by 19.8%.

## 6. Discussion

The experimental findings demonstrate that while leading LLMs possess
strong high-level semantic understanding, their baseline token awareness
on public benchmarks like TASE is heavily inflated by dataset
memorization. The uniform 21--25% performance drop observed on
MultilingualToken-ZeroDay highlights the necessity of using sequestered,
programmatically generated evaluation suites when assessing true
low-level linguistic structure parsing.

Furthermore, the success of Token-Structure Verification
Chain-of-Thought (TSV-CoT) proves that fine-grained token manipulation
requires explicit procedural deconstruction. Without reasoning
scaffolds, autoregressive generation relies on high-level semantic
associations that fail at the subword boundary level. Forcing models to
explicitly map tokenization chunks and simulate step-by-step arithmetic
ensures significantly higher fidelity to ground-truth token layouts
across multilingual environments.

Several limitations should be noted. The evaluation utilized fixed
inference settings ($T = 0.0$), and the benchmark focused on a static
subset of ten task types across three languages. Future work should
expand this evaluation framework to streaming tokenizers, larger
multi-token vocabulary architectures, and reinforcement learning
fine-tuning pipelines designed specifically for low-level structural
awareness. Overall, this study provides a standardized,
contamination-resistant baseline for evaluating LLMs on multilingual
token awareness.
