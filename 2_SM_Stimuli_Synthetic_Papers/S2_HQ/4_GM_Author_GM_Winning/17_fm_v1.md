## Summary / Abstract

Large Language Models (LLMs) are increasingly deployed as
decision-making backbones for embodied reasoning and action planning in
interactive environments, yet rigorous, controlled comparisons across
frontier models remain scarce. This study presents a comparative
benchmark of six state-of-the-art LLMs---Gemini 3.1 Pro, GPT-5.4 Pro,
Grok 4, Qwen-2.5, Claude Sonnet 4.5, and DeepSeek-v3---evaluating their
multi-step reasoning, spatial grounding, and closed-loop trajectory
execution capabilities. Using the EmbRACE-3K benchmark within
photorealistic Unreal Engine environments via UnrealCV-Zoo, models were
evaluated across 570 held-out test trajectories (from a total of 713
task instances). Performance was measured using closed-loop Task Success
Rate (SR), Goal Condition Success (GCS), and Mean Reciprocal Rank (MRR)
for candidate action grounding. Gemini 3.1 Pro achieved the highest
overall Task Success Rate (78.2%) and MRR (0.879), significantly
outperforming all other evaluated models ($p < .001$). Our findings
demonstrate that long-horizon spatial state tracking and failure
recovery are the key differentiators in embodied performance,
establishing a standardized baseline for interactive embodied AI
evaluation.

## 1. Introduction

Recent advances in Large Language Models (LLMs) have expanded their
application from textual reasoning to high-level policy generation and
action planning in embodied systems. However, model capabilities on
general-purpose linguistic benchmarks do not reliably translate to
embodied reasoning and action in interactive environments. Interactive
environments introduce unique challenges, including partial
observability, spatial orientation, multi-step dependency management,
and dynamic state transitions following physical feedback.

Existing evaluations suffer from fragmented task definitions and
inconsistent execution feedback loops, making controlled comparisons
across heterogeneous model families difficult. To resolve these
limitations, this study evaluates six frontier LLMs---Gemini 3.1 Pro,
GPT-5.4 Pro, Grok 4, Qwen-2.5, Claude Sonnet 4.5, and
DeepSeek-v3---under a unified, closed-loop interactive framework. By
measuring task execution success, fine-grained goal fulfillment, and
action ranking accuracy, this paper establishes a reproducible benchmark
and isolates key architectural and reasoning factors that drive embodied
performance.

## 2. Related Work

Prior research relevant to this benchmark spans three core domains: LLM
general reasoning benchmarks, language-guided embodied decision-making,
and interactive environment design. While benchmarks like ALFRED,
VirtualHome, and BEHAVIOR have established foundation tasks for embodied
agents, comparative LLM evaluations often focus on intra-family model
iterations or operate in static, open-loop settings without
environmental state changes. Furthermore, standardized evaluation
protocols that combine step-wise candidate action grounding with
end-to-end trajectory fulfillment remain underexplored. This work
bridges this gap by conducting a controlled, multi-metric comparison
across six diverse LLM families in a real-time, stateful simulator.

## 3. Data

Evaluations were conducted on **EmbRACE-3K**, a benchmark suite
comprising 713 language-guided embodied task instances situated in
photorealistic Unreal Engine environments rendered through the
UnrealCV-Zoo interface. Tasks encompass three primary categories:
multi-room object navigation, interactive spatial rearrangement, and
sequential object manipulation under partial observability.

The dataset was split into a 20% development set (143 tasks) for prompt
calibration and trajectory formatting, and an 80% test set (570 tasks)
reserved strictly for final model evaluation. Each task instance
provides structured textual and visual feedback, dynamic state
transition logs, and validated expert execution graphs for metric
ground-truthing.

## 4. Methodology

The six target models---Gemini 3.1 Pro, GPT-5.4 Pro, Grok 4, Qwen-2.5,
Claude Sonnet 4.5, and DeepSeek-v3---were evaluated under an identical
closed-loop interactive agent architecture. At each step $t$, the agent
receives the current task goal, structured sensory/state feedback from
UnrealCV-Zoo, and its prior action history, prompting it to select or
rank executable downstream actions. All models were queried using
deterministic decoding parameters ($T = 0.0$, $top\_ p = 1.0$) with
identical system prompts.

Performance was evaluated using three primary metrics:

1.  **Task Success Rate (SR):** The proportion of test episodes where
    all task conditions were fully satisfied within a maximum step
    threshold ($N_{\max} = 30$).

2.  **Goal Condition Success (GCS):** The macro-averaged percentage of
    sub-goals successfully completed per trajectory (evaluating partial
    completion).

3.  **Mean Reciprocal Rank (MRR):** Measures action-grounding accuracy
    by assessing the position of the optimal valid action within the
    model\'s top-$k$ candidate ranking at each decision node.

Statistical significance was assessed using Cochran's $Q$ test for
overall multi-model variance, followed by post-hoc pairwise McNemar's
tests with Holm-Bonferroni correction ($\alpha = 0.05$) on binary task
success outcomes. Effect sizes were computed via Cohen's $h$, and 95%
confidence intervals were generated using non-parametric bootstrapping
across 1,000 iterations.

## 5. Results

Performance varied significantly across the six models, with Gemini 3.1
Pro securing the highest scores across all primary and secondary
metrics.

An omnibus Cochran's $Q$ test confirmed significant overall variance
across models ($Q(5) = 42.15,p < .001,w = 0.25$). Post-hoc McNemar tests
demonstrated that Gemini 3.1 Pro significantly outperformed Claude
Sonnet 4.5 ($p = .018,h = 0.16$) and all subsequent models ($p < .001$).

Qualitative error analysis revealed that performance gaps widened on
long-horizon tasks requiring more than 15 action steps. While
open-weight models (Qwen-2.5, DeepSeek-v3) performed competitively on
short-horizon navigational tasks, they exhibited higher rates of plan
derailment and repetitive action looping after environmental execution
failures.

## 6. Discussion

Gemini 3.1 Pro demonstrated superior performance in embodied reasoning
and interactive action execution, maintaining higher plan fidelity and
recovering more effectively from non-deterministic state feedback. Its
high MRR (0.879) indicates precise action grounding at individual
decision points, minimizing exploration overhead.

### Key Factors and Limitations

- **Architectural & Fine-Tuning Factors:** The performance gap suggests
  that advanced multi-step instruction tuning and long-context state
  tracking contribute directly to embodied resilience.

- **Limitations:** The scope was limited to the EmbRACE-3K suite in
  Unreal Engine; performance across real-world physical robotics or
  alternative simulators (e.g., Habitat, Isaac Gym) remains to be
  validated. Fixed hyperparameter settings ($T = 0.0$) may also
  disadvantage models optimized for sample-based sampling techniques.

- **Future Directions:** Subsequent work will expand to closed-loop
  visual-language inputs (VLM end-to-end control) and evaluate zero-shot
  adaptation to stochastic physical perturbations.
